# LocalGB — Gilgit-Baltistan, As Locals Tell It

A Next.js + TypeScript travel site for Gilgit-Baltistan targeting tourists who want honest, local guidance on budget travel, destinations, treks, and vetted agencies.

## Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- SEO-first architecture (~140 pages)

## Project Files
- `index.html` — Homepage design preview (open in browser)
- `SEO-ARCHITECTURE.md` — Full keyword-driven site architecture (~140 pages across 8 tiers)

## Site Structure (planned)
- `/hunza/` `/skardu/` `/gilgit/` `/fairy-meadows/` — Core destination hubs
- `/trekking/` — K2, Gondogoro La, Rakaposhi, and 15+ more
- `/tours/` `/agencies/` — Monetization hub (agency referrals)
- `/travel/` — Budget guides, itineraries, logistics
- `/things-to-do/` `/hidden-valleys/` `/mountains/`

## Monetization
Agency referral deals + hotel affiliate (Booking.com partner program)

## Target Keywords
Top terms from competitor analysis: gilgit weather (60.5k), hunza weather (49.5k), fairy meadows (18.1k), naran (22.2k), shandur polo festival (1.9k), and 850+ more.
